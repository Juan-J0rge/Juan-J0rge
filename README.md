## 👨‍💻 Sobre mim

Olá! Sou o Juan, estudante de Ciência da Computação em Maceió - AL. Atualmente trabalho como instrutor de informática e desenvolvo projetos Back-end, Front-end e Full Stack.

Meu foco é o **desenvolvimento Back-end com Java e Spring Boot**, construindo APIs REST e trabalhando com JPA, Hibernate e bancos de dados relacionais como PostgreSQL e MySQL. No Front-end, tenho experiência com React, JavaScript, TypeScript, HTML e CSS. Tenho formação em Full Stack Java pela EBAC.

Fora do código, gosto de ver filmes, escutar música e ler livros. 🎬🎧📚
